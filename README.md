# CiptaCoding Fix - Solusi Digital & Jasa Pembuatan Website / Bimbingan Coding IT

Website resmi dan landing page CiptaCoding Studio dengan arsitektur bersih, responsive, modern, dan performa tinggi.

## 🚀 Fitur Utama
- **Beranda (`index.html`)**: Hero section interaktif, value proposition, statistik pencapaian, running marquee tech stack logo (Devicon), ringkasan layanan, standar keunggulan, ulasan klien, dan WhatsApp CTA.
- **Layanan (`layanan.html`)**: Katalog 4 pilar layanan utama IT, modul bimbingan tugas/skripsi, dan SLA waktu pengerjaan.
- **Cara Order (`cara-order.html`)**: 4 langkah alur pemesanan terstruktur dengan estimasi pengerjaan transparan.
- **Portofolio (`portofolio.html`)**: Galeri studi kasus proyek dengan filter tab dinamis (Skripsi, Web Bisnis, Mobile App, AI/ML).
- **Tanya Jawab (`tanya-jawab.html`)**: Pusat bantuan FAQ dengan interaksi accordion expand/collapse.

## 🛠️ Menjalankan Secara Lokal
Cukup buka file `index.html` langsung di browser, atau jalankan local web server:
```bash
python -m http.server 8000
```
Lalu buka `http://localhost:8000` di browser.
